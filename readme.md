⏱️ 근무시간 정산 리포트 Pro+ (Single File Version)

복잡한 서버 설정이나 설치 과정 없이, index.html 파일 하나만으로 근무 시간을 정산하고 관리할 수 있는 도구입니다. CSS와 JavaScript 로직이 모두 HTML 파일 내부에 통합되어 있습니다.

📌 프로젝트 소개

근무 기록(CSV)을 업로드하여 주간/월간 근무 시간을 자동으로 계산하고, 목표 시간 달성 현황과 초과 근무에 따른 보상 휴가를 시뮬레이션합니다.

✨ 주요 기능

⚡ 단일 파일 실행 (All-in-One)

별도의 CSS, JS 파일 없이 index.html만 있으면 어디서든 실행 가능합니다.

Tailwind CSS는 CDN을 통해 로드됩니다.

📊 직관적인 리포트

주간/월간 보기: 근무 기록을 기간별로 그룹화하여 보여줍니다.

시각화: 진행률 바(Progress Bar)를 통해 근무 강도를 한눈에 파악합니다.

🎯 목표 관리 및 시뮬레이션

주간 목표 설정: 기본 40시간 목표를 설정하고 달성률을 확인합니다.

스마트 1/N: 남은 평일 동안 하루 평균 몇 시간을 근무해야 목표를 달성하는지 계산해 줍니다.

보상 휴가 계산: 40시간 초과분에 대해 1.5배 가산된 보상 휴가(연차/반차 등)를 자동으로 산출합니다.

⚠️ 규정 위반 알림

코어 타임 체크: 설정된 코어 타임(예: 12:30 ~ 17:30) 준수 여부를 확인합니다.

주 52시간 경고: 법정 근로 시간 초과 시 경고 메시지를 표시합니다.

🚀 사용 방법

저장소의 index.html 파일을 다운로드합니다.

크롬(Chrome), 엣지(Edge), 사파리(Safari) 등 최신 웹 브라우저에서 파일을 엽니다.

우측 상단 CSV 파일 업로드 버튼을 클릭하여 근태 기록 파일을 선택합니다.

분석된 결과를 확인하고, 필요 시 웹 화면상에서 시간을 직접 수정하여 시뮬레이션할 수 있습니다.
